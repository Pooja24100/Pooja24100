## What I've built

<img src="assests/card-01-blaze.svg" width="100%" alt="01, Blaze Tingg, in production: editable multi-step AI pipelines. Text, image and video are generated through pipelines that can be reviewed, approved or regenerated. A brief goes to OpenAI or Claude, the work runs as an asynchronous job, the interface polls for status, and the result reaches a review gate that can approve it or send it back to be regenerated. Long jobs report progress by polling, so the interface never blocks. Built with Next.js, Python, OpenAI, Claude, Material UI, REST APIs and Nginx.">

<img src="assests/card-02-genai.svg" width="100%" alt="02, GenAI Job Preparation Platform, solo and open source: AI career tools with the keys kept server-side. Interview generation, resume analysis and skill-gap detection all run on the server. The browser calls an Express API protected by JWT authentication and role-based access control, and only that server talks to Gemini and to MongoDB. The browser never holds a model key or a prompt. Built with React.js, Node.js, Express.js, MongoDB, Gemini AI and JWT.">
